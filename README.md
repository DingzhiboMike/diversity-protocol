# diversity-protocol

Скилл для Claude.

Протокол множественной генерации без схлопывания к одному ответу. Когда нужно ≥3 вариантов (заголовков, позиционирования, концепций), заставляет варианты различаться по смысловой оси, а не по формулировке. Основан на методе String Seed of Thought (Sakana AI, ICLR 2026). Два режима: блок для промпта LLM и редакторская дисциплина.

## Когда использовать

- Нужно N действительно разных вариантов
- AI всё время выдаёт одно и то же
- Собираете промпт для генерации вариантов

Не подходит для задач с одним правильным ответом, строгих шаблонов и диагностики.

## Установка

**Claude Code.** Склонируйте репозиторий в папку скиллов:

```bash
git clone https://github.com/DingzhiboMike/diversity-protocol.git ~/.claude/skills/diversity-protocol
```

**Claude.ai / десктоп-приложение.** Скачайте репозиторий как ZIP (Code → Download ZIP) и загрузите его в настройках Claude, в разделе со скиллами.

После установки скилл включается сам, когда запрос подходит под его описание. Можно вызвать и явно — по имени `diversity-protocol`.
